# GATED.md

Changes under these paths require an accepted spec named in the session prompt (spec 003 §8).

- `crates/tshes/**`
- `golden/**`: new rows need provenance meta; changed rows need an in-place `[CORRECTED yyyy-mm-dd: …]` record
- `docs/specs/**`: accepted specs change only by revision. A round's own new spec file, its committed prompt in `docs/specs/prompts/` (an ADDENDUM is appended, nothing else changes), and its row in `docs/specs/INDEX.md` are not changes to an accepted spec.
- `docs/METHOD.md`: only by an amendment spec
- `GATED.md` itself
