# Round prompts

Every round's prompt, committed by the round as its first commit and byte-identical to the file the advisor wrote (`docs/ROUNDS.md` §2). A dated ADDENDUM is appended to the same file; the text above it is never edited.

File name: `NNN-short-name.md`, matching the round's spec, `docs/specs/NNN-short-name.md`. This directory sits outside the `docs/specs/*.md` glob, so it never affects the next free spec number.
